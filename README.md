One line for "The Printer Finally Answers": the office printer, having kept a numbered log of every time you hit it, declines percussion as a device driver. `main.py` reads the line from `entry.txt` and writes those exact 62 bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), checking the 1–240 character gate before it writes. Stdlib only, byte-identical on every run.

## Run it

```sh
python3 main.py
```
